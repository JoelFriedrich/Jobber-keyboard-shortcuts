# Privacy Policy — Jobber Shortcuts

**Last updated: May 18, 2026**

---

## Overview

Jobber Shortcuts is a Chrome extension that provides keyboard shortcuts for use on [secure.getjobber.com](https://secure.getjobber.com). This privacy policy explains what data the extension does and does not collect.

---

## Data Collection

**Jobber Shortcuts collects no user data. None.**

The extension does not collect, store, transmit, or share any information about you or your activity — ever.

---

## What the extension does

Jobber Shortcuts runs entirely within your browser. When you press a keyboard shortcut on a Jobber page, the extension interacts with the current page's DOM to click buttons or navigate to URLs within Jobber. All of this happens locally in your browser tab.

---

## Permissions explained

The extension requests the following Chrome permissions, each used solely to provide keyboard shortcut functionality:

- **activeTab** — used to interact with the currently active Jobber tab when a shortcut is triggered
- **scripting** — used to inject the keyboard shortcut listener into Jobber tabs that were open before the extension was installed
- **tabs** — used to read the current tab's URL so the popup can show whether shortcuts are active on the current page

None of these permissions are used to collect, read, or transmit any user data.

---

## Third parties

Jobber Shortcuts does not share any data with third parties because it does not collect any data to share. The extension has no analytics, no tracking, no advertising, and no external network requests of any kind.

---

## Remote code

Jobber Shortcuts does not use any remote code. All JavaScript is bundled within the extension package.
